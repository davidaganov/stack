An interactive CLI tool to create modern web projects with a focus on speed, structure, and best practices.

Build **Vue PWA**, **Vue Lynx**, or **Astro** projects in seconds with a beautiful, guided experience.

---

## ✨ Features

- **Interactive Setup** — Guided CLI wizard.
- **Smart Generation** — Choose between Recommended, Custom, or Empty project presets.
- **Always Up-to-Date** — Clones templates directly from GitHub to ensure you have the latest core structure.

---

## 🚀 Quick Start

**1. Run the generator**

No installation required, just use `npx`:

```bash
npx @davidaganov/stack
```

## 💻 CLI Commands

| Command                | Description                                    |
