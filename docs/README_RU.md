Интерактивный CLI-инструмент для развертывания современных веб-проектов с упором на скорость, структуру и лучшие практики.

Создавайте проекты на базе **Vue PWA**, **Vue Lynx** или **Astro** за считанные секунды с помощью удобного и красивого интерфейса.

---

## ✨ Возможности

- **Интерактивная настройка** — Пошаговый мастер CLI.
- **Умное развертывание** — Выбор между рекомендованным, кастомным или пустым пресетом проекта.
- **Всегда актуально** — Клонирует шаблоны напрямую с GitHub, гарантируя свежую структуру ядра.

---

## 🚀 Быстрый старт

**1. Запустите генератор**

Установка не требуется, просто используйте `npx`:

```bash
npx create-web-stack
```

## 💻 Команды CLI

| Команда                | Описание                                     |
